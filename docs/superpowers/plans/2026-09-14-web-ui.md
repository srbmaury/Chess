# Chess ML Coach Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a local FastAPI + React web application that reuses the existing Chess ML Coach pipeline and training state, provides interactive puzzle practice, mistake/progress views, and launches long-running pipeline stages with visible progress.

**Architecture:** Python remains authoritative for chess rules, Stockfish work, puzzle scheduling, and persisted artifacts. A FastAPI layer exposes typed local APIs and an in-process single-job pipeline manager with SSE progress; a React/Vite frontend consumes those APIs and renders the dashboard, interactive board, mistake explorer, progress views, and pipeline controls. Production use is started through `chess-coach ui` and serves the built frontend from the same local server.

**Tech Stack:** Python 3.11+, FastAPI, uvicorn, Pydantic, python-chess, SQLite, React 19, TypeScript, Vite, react-chessboard, chess.js, Recharts, Vitest, React Testing Library.

**Spec:** `docs/superpowers/specs/2026-09-13-web-ui-design.md`

## Global Constraints

- Default host is exactly `127.0.0.1`; do not expose the app on all interfaces by default.
- Existing `sync`, `analyze`, `features`, `train`, `report`, `puzzles`, `practice`, and `progress` CLI behavior must remain compatible.
- FastAPI must call shared Python services; it must not reimplement Stockfish analysis, feature generation, model training, puzzle extraction, or spaced-repetition scheduling.
- Practice APIs must not reveal `best_move_uci` or `best_move_san` before the user submits an attempt.
- Puzzle practice never launches Stockfish.
- Pipeline manager allows one running job at a time and keeps the existing analyzer single-writer lock as the final cross-process guard.
- Personal artifacts remain under `data/` and `models/` and remain gitignored.
- Frontend production build is served locally by FastAPI; Vite dev mode proxies `/api` to FastAPI.
- Tests must not require Chess.com network access or a real Stockfish binary.
